# Summerer 크롬 확장 프로그램

AI 채팅 대화를 요약해 [Summerer](https://summerer.vercel.app) 블로그에 타임라인으로 저장하는 크롬 확장 프로그램입니다. (PC 크롬 전용)

- **본문 전체 요약하기**: 지금 보고 있는 대화를 AI가 장면별로 요약 → 미리보기에서 수정 → 새 글로 저장하거나 기존 글에 덮어쓰기
- **요약에 덧붙이기**: 대화에서 텍스트를 드래그 → 선택한 글의 요약 맨 앞에 추가
- **인용으로 저장**: 대사를 드래그 → 말한 사람을 고르면 선택한 글의 QUOTE 탭에 대사로 저장

현재 지원하는 AI 채팅: **Caveduck**

## 설치 방법

1. 이 페이지 위쪽의 초록색 **Code** 버튼 → **Download ZIP**을 눌러 내려받습니다.
2. 내려받은 압축 파일을 풉니다. 풀린 폴더는 지우지 말고 계속 둘 곳에 옮겨 두세요. (폴더를 지우면 확장도 사라집니다)
3. 크롬 주소창에 `chrome://extensions` 를 입력해 엽니다.
4. 오른쪽 위 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 2번에서 푼 폴더(`manifest.json` 파일이 들어 있는 폴더)를 선택합니다.
6. 주소창 오른쪽 퍼즐 아이콘에서 Summerer를 고정(📌)하면 편합니다.
7. Summerer 아이콘을 누르고 **Google로 로그인**합니다. 블로그와 같은 구글 계정을 쓰세요.

> 크롬이 "개발자 모드 확장 프로그램" 안내를 띄울 수 있습니다. 웹스토어를 거치지 않고 설치했기 때문이며, 그대로 사용하셔도 됩니다.

## 업데이트 방법

1. 새 버전을 위와 같이 내려받아 압축을 풉니다.
2. 기존에 설치한 폴더 안의 파일을 새 파일로 **덮어씁니다**. (폴더 위치는 그대로)
3. `chrome://extensions` 에서 Summerer 카드의 새로고침(↻) 버튼을 누릅니다.

같은 폴더를 덮어쓰면 로그인 상태가 그대로 유지됩니다.

## 이용 안내

- AI 요약은 1인당 하루 5회까지 할 수 있습니다.
- 확장 프로그램은 지원하는 AI 채팅 사이트에서, 사용자가 버튼을 눌렀을 때만 화면의 대화를 읽습니다.
